# Shared predigested data

The shared directory contains compressed diversity/FdM windows, compact
interval tables, QTL/marker tables, gene-level coding summaries, and
chromosome lengths.

The eight-population Pool-seq VCF is archived separately on
[Zenodo (DOI: 10.5281/zenodo.23099934)](https://doi.org/10.5281/zenodo.23099934).
Download `8pop_poolseq.vcf.gz` into this directory when reproducing the
population-structure analysis.
